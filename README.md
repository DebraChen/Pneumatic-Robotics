# Pneumatic-Robotics
An experimental development journal exploring Arduino electronics, pneumatic actuation, soft robotics, and embodied interaction — from basic circuits to multi-channel robotic systems. 

**From Basic Electronics to Embodied Robotic Systems**

An open development journal tracing a hands-on learning and prototyping process: from an LED and resistor to Arduino-controlled pneumatic actuation, multi-channel soft robotics, custom electronics and embodied interaction.

## Why this repository?

This project documents both *how* pneumatic robotic systems are built and *why* their material behaviour matters.

Alongside circuits, code and technical tests, it records failures, design decisions and reflections relevant to biomorphic, wearable and non-humanoid robotic art.

## Intended System

The proposed system comprises 6 (or 3*2, depending on the needs) independent pneumatic groups, each with one air pump, two valves and one three-position user switch.

The development progresses from basic electronic experiments towards custom PCB design, system integration and embodied robotic behaviour.

## Research Direction

The long-term aim is to investigate **embodied robotic behaviour, material agency and human–non-human relationships** through soft actuation.

The documentation connects practical prototyping with artistic questions of movement, perception, character and interaction.
